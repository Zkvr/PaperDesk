# PaperDesk changelog

## 0.8.0-beta

- Restore open desktop notes and stacks after exiting PaperDesk from the tray and launching it again.
- Reuse the Windows desktop layer across open sheets and limit retries when Explorer cannot provide it.
- Add an optional lightweight editor that uses the built-in Windows controls after restarting PaperDesk.
- Show compatible GitHub updates beside Settings. Installed copies open Setup and portable copies replace their program files and restart with the same data folder.

## 0.7.0-rc

- The Windows app, installer, GitHub tag check and WinGet manifests use the same version.
- Release builds produce an offline x64 installer, a portable ZIP and SHA-256 checksums. The release candidate is marked as a prerelease.
- Added a Windows guide for installation, updates, backup, recovery, and local storage.

## 0.6.0-beta

- Graphite, Ocean and Clay themes apply immediately.
- Notes have 12 paper colors, three textures, corner and shadow options, paper transparency, and six desktop sizes.
- Optional edge snapping works with animations turned off. Paper motion follows the Windows animation preference.

## 0.5.0-beta

- Keyboard search, favorites at the top of each group, and bulk extraction from stacks.
- Duplicate notes with attachments and styling. The manager and desktop sheets share the saved text size.
- Optional sample note and a shortcut and gesture guide under F1.

## 0.4.0-beta

- Virtualized card layouts, faster incremental list updates, and recovery for notes placed on a disconnected display.
- Improved WebView2 lifetime management, Windows packaging checks and build audits.
