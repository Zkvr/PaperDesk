# PaperDesk для Windows

[English guide](USER-GUIDE.md)

PaperDesk размещает заметки на рабочем столе. В сборки Windows x64 входит .NET. Установщик принимает Windows 10 начиная со сборки 19041. Этот кандидат проверен на Windows 11 x64. Если среда Microsoft Edge WebView2 недоступна, приложение открывает встроенный редактор.

## Установка и обновление

1. Откройте [релизы PaperDesk](https://github.com/Zkvr/PaperDesk/releases). Скачайте установщик или портативный ZIP и файл `SHA256SUMS.txt` из того же релиза. Беты и кандидаты отмечены как **Pre-release**.
2. Сверьте SHA-256 скачанного файла со строкой для его имени. Для установщика выполните в PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath .\PaperDesk-Setup-win-x64.exe`. Для ZIP подставьте имя архива.
3. Запустите `PaperDesk-Setup-win-x64.exe` для установки под текущим пользователем Windows. Для портативного запуска распакуйте весь ZIP в папку с доступом на запись и откройте `PaperDesk.exe`.

Перед обновлением сделайте JSON-копию и завершите PaperDesk через **Выход** в трее. Для установленной программы запустите новый установщик в текущую папку установки. Для портативной версии распакуйте новый ZIP в отдельную папку и скопируйте прежнюю папку `data` рядом с новым `PaperDesk.exe`, пока обе копии закрыты. Запустите новую версию и проверьте заметки.

Удалить установленную программу можно через **Параметры Windows → Приложения → Установленные приложения**. После повторной установки PaperDesk откроет заметки из профиля Windows. У портативной версии заметки находятся внутри папки приложения. Перед удалением этой папки сохраните JSON-копию или скопируйте `data`.

## Заметки, резервные копии и восстановление

- **Ctrl+Alt+N** создаёт листик на столе. **Ctrl+Alt+Space** вызывает открытые листики. В менеджере **Ctrl+F** открывает поиск, а **F1** показывает горячие клавиши и жесты.
- Цветная точка на листике открывает его оформление. Тема приложения меняется в разделе **Параметры → Оформление**.
- В менеджере выберите **Файл → Экспортировать копию… → Резервная копия JSON**. В JSON входят заметки, вложения, архив, корзина, стопки и оформление листиков. Для читаемой копии текста доступен Markdown.
- Для восстановления выберите **Файл → Импортировать заметки…** и укажите JSON. Если в профиле уже есть заметка с таким идентификатором, импорт добавит отдельную копию. Для восстановления всей библиотеки удобно использовать пустой профиль.
- Чтобы сохранить также общие параметры, выйдите из PaperDesk через трей и скопируйте всю папку `data`. Точный путь виден в **Параметрах**. Для полного восстановления закройте PaperDesk и поместите копию по этому пути. Сохраните текущую папку отдельно, пока не убедитесь, что восстановленные заметки открываются.

## Локальные данные и конфиденциальность

Windows-версия с GitHub хранит заметки, вложения и параметры на компьютере. Она работает офлайн без аккаунта. Установленная версия использует `%LOCALAPPDATA%\PaperDesk\data`. Портативная версия использует папку `data` рядом с `PaperDesk.exe`.

JSON-копия и папка `data` могут содержать весь текст заметок и изображения. Храните их там, где вы контролируете доступ. Локальный журнал диагностики записывает категории и коды ошибок. Обновления среды WebView2 обслуживает Windows.
